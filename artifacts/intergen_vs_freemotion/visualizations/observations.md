# 固定 case 的可视化观察

测试 ID 1、4、6 在生成前固定；不是从指标较好的结果中挑选。GIF 为原始物理坐标骨架，每两帧显示一帧，未做平滑、actor 平移或重定向。以下观察来自五帧 contact sheet；GIF 保存了更完整的时间过程，可继续人工检查。

| Test ID / 文本语义 | InterGen zero-B single（显示独立 A） | InterGen native two-person |
|---|---|---|
| 1 / 打招呼、握手 | 人体骨架可辨认，手臂从展开到放下再展开；看不出明确的握手细节。 | 两人中段靠近、抬臂，头尾均有展开双臂姿态；投影中有重叠，不能据此证明正确手部接触或没有穿插。 |
| 4 / 身体前倾、用力握手交谈 | 大多保持站立和屈肘姿态，五个抽样帧变化较小；明显前倾、用力握手不突出。 | 两人有屈肘、手臂靠近，但主要姿态变化也较小；不能确认“用力握手”的细节。 |
| 6 / 松开握持并站起来 | 从跨步、抬臂姿态做有限变化，未呈现与双人相同的明显蹲下到站起。独立生成的两条 A 也不呈现清楚的同步起身。 | 两人从较低、接近的姿态逐渐站直，“站起来”在抽样帧中较清楚；握持/松开的接触精度仍无法由骨架投影确认。 |

保存的数组全部为有限数值。三例的单人平均相邻帧关节位移约 0.0052 / 0.0042 / 0.0075 m；双人约 0.0078 / 0.0049 / 0.0139 m，说明并非数值上完全静止，但不是动作质量指标。

这些有限案例显示 zero-B 路径能输出可辨认骨架，部分文本动作不明显；native 双人在 case 6 更容易辨认共同起身。不能把三例推广为整体质量结论，也没有做碰撞、足滑或精确手部接触检测。单人配对 contact sheet 仅展示评测输入，两条动作没有接受彼此条件。
